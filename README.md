# CleanMyHome

CleanMyHome is a shell script for macOS that helps clean the Home folder of a mobile developer who uses Android Studio (AS).

It focuses on removing caches, logs, temporary files, and Android Studio related data that can accumulate over time in a development environment.

## Languages

- English (default)
- Italiano
- Deutsch
- Français
- Español

## English

CleanMyHome helps keep a macOS development machine tidy by cleaning common system files, temporary data, and Android Studio related artifacts from the Home directory.
